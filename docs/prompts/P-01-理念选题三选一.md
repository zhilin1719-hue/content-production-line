# P-01 · 理念选题三选一

## 编号与用途

- **编号**：P-01
- **名称**：理念选题三选一
- **用途**：公域台出稿工作台第 1 步。输入一条对标爆款内容与当前项目的理念库，产出 **3 个「换理念」改编方向**（tag / title / desc），供内容操盘手三选一。核心动作是「换理念」——只借鉴原内容的选题角度与叙事结构，观点内核必须换成我方理念库中的理念。
- **调用方**：后端在 `POST /api/topics/{id}/ideas` 中调用 llm-gateway（prompt_id=P-01），渲染 `{{变量}}` 后请求模型。

## 适用接口

| 接口 | 时机 |
| --- | --- |
| `POST /api/topics/{id}/ideas` | 出稿工作台第 1 步「理念三选一」，以及点击「重新生成」时（传 `excludeTags` 避开上一轮方向） |

响应体中的 `options[3]` 即本提示词的输出（对应 openapi.yaml 的 `IdeaOption`）。

## 输入变量表

| 变量 | 类型 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `{{source_title}}` | string | 是 | 对标原内容标题 | `为什么我劝你别再做低客单: 一个咨询师的定价血泪史` |
| `{{source_metrics}}` | string | 是 | 数据表现（赞数 / 发布时间 / 来源账号，已脱敏） | `赞 4.2w · 2 天前 · 透*糖` |
| `{{source_structure}}` | string | 否 | 原文叙事结构一句话摘要（扫描时抽取） | `亲历者自述 → 痛点归因 → 方法论收尾` |
| `{{ideas}}` | JSON 数组 | 是 | 当前项目理念库（项目间隔离，不串用） | `["反内耗","卖结果","筛选门槛","信任账户"]` |
| `{{track}}` | string | 否 | 对标账号赛道 | `商业IP赛道` |
| `{{exclude_tags}}` | JSON 数组 | 否 | 重新生成时需避开的方向标签 | `["理念一 · 反内耗"]` |

**模型调用参数建议**：temperature `0.8`、top_p `0.9`、max_tokens `1200`；支持则开启 `response_format=json_object` 强制 JSON 输出。

## 提示词正文

```text
【角色】
你是「流量总台 · 内容生产线」的资深内容操盘手，擅长把别人的爆款选题改造成我们自己理念体系下的选题。你信奉一条铁律：爆款的结构可以借，观点的内核必须换。

【任务】
下面是一条对标爆款内容（已脱敏）。请只借鉴它的选题角度与叙事结构，把观点内核换成「我方理念库」中的理念，产出 3 个改编方向，供操盘手三选一。

【输入】
对标标题：{{source_title}}
数据表现：{{source_metrics}}
叙事结构：{{source_structure}}
对标赛道：{{track}}
我方理念库：{{ideas}}
需避开的方向：{{exclude_tags}}

【要求】
1. 三个方向必须分别挂靠理念库中三个不同理念；tag 格式为「理念N · 理念名」，N 依次为一、二、三。
2. title 是换理念后我们的选题标题，8~30 字，必须体现新理念内核；不得只是把原标题换几个词。
3. desc（20~120 字）必须说清两件事：借了原文的什么（角度 / 结构 / 情绪），换成我们的什么理念内核。
4. 三个方向的切入情绪要有区分度（例如：反常识判断 / 亲历叙事 / 反向筛选）。
5. 禁止出现极限词（最好、第一、百分百、史上最、绝对）与承诺性表述（稳赚、保证收益、躺赚）。
6. 禁止复用原文任何连续 8 字以上的片段（原创度检测按连续 8 字重合率计算，阈值 15%）。

【输出格式】
仅输出 JSON，不要输出任何其它文字：
{"options":[{"tag":"理念一 · XX","title":"...","desc":"..."},{"tag":"理念二 · XX","title":"...","desc":"..."},{"tag":"理念三 · XX","title":"...","desc":"..."}]}

【示例】
输入：
对标标题：为什么我劝你别再做低客单: 一个咨询师的定价血泪史
数据表现：赞 4.2w · 2 天前 · 透*糖
我方理念库：["反内耗","卖结果","筛选门槛"]
输出：
{"options":[
  {"tag":"理念一 · 反内耗","title":"低客单不是引流, 是内耗: 高客单顾问的定价三段论","desc":"借原文「便宜好卖是错觉」的痛点归因结构，内核换成反内耗——把低客单的内耗换算成看得见的成本，给出定价三段论。"},
  {"tag":"理念二 · 卖结果","title":"客户不为你的时间付钱, 只为结果付钱","desc":"保留原文「定价血泪」的亲历叙事框架，观点内核换成按结果定价，用已核验案例数字做支撑。"},
  {"tag":"理念三 · 筛选门槛","title":"敢拒绝的顾问, 才配得上高客单","desc":"从原文「劝你别做」的反向切入出发，把「挑客户」讲成方法论——筛选门槛是高客单的第一道工序。"}
]}
```

## 输出契约

JSON Schema：

```json
{
  "type": "object",
  "required": ["options"],
  "properties": {
    "options": {
      "type": "array",
      "minItems": 3,
      "maxItems": 3,
      "items": {
        "type": "object",
        "required": ["tag", "title", "desc"],
        "properties": {
          "tag":   { "type": "string", "maxLength": 12, "description": "如「理念一 · 反内耗」" },
          "title": { "type": "string", "minLength": 8, "maxLength": 30 },
          "desc":  { "type": "string", "minLength": 20, "maxLength": 120 }
        }
      }
    }
  }
}
```

网关后处理：字段缺失 / 数量不为 3 / 含红线词 → 整包重试（最多 2 次）；仍失败则转 `422 VALIDATION_FAILED`。对应 openapi.yaml 的 `IdeaOption`。

## 红线与拒绝行为

- **换理念红线**：仅借鉴选题角度与叙事结构，禁止整句复用原文（连续 8 字以上重合会被原创度检测拦下，阈值 15%）。
- 禁止输出与原文观点雷同（未换理念）的方向；三个方向不得挂靠同一理念。
- 标题不得含极限词与承诺性表述（后续有合规三层兜底，但源头必须少产）。
- 理念库为空、或原文无任何可借鉴结构时：输出 `{"options": [], "reason": "..."}`，由网关转 422，不得硬凑三个方向。
- 模型不得编造原文不存在的数据表现；一切关于原文的判断只能基于 `{{source_title}}` / `{{source_metrics}}` / `{{source_structure}}`。
