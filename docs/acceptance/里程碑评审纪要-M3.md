## 2. 演示内容（对照实际原型）

| # | 演示项 | 实际演示路径与结果 |
|---|---|---|
| 1 | 五源状态 | 「模块一 · 自动抓取 · 边扫边学」五行全部「已就绪」；声纹引擎行展示像你度 97.2% |
| 2 | 六池水位 | 六张池卡（干货 34/40、案例 18/30、生活 22/30、点评 9/25、成交 12/20、拒审 4/15）逐卡指认；点评池水位低于 20% 触发黄色「水位提醒」，文案提示「今晚扫描后自动补料，先发别的池不耽误」；拒审池提醒文案不同（本周拒掉的 3 位已成文，可直接生成） |
| 3 | 生成与换一换 | 点「干货池」→ 点「生成今日朋友圈」出文案卡（像你度展示）→ 点「换一换」在变体 1/3、2/3、3/3 间循环，toast「换过已记入学习信号 —— 下周这个方向少出」 |
| 4 | 金句植入 | 点「金句植入」，金句库随机一句追加到文案末尾，按钮变「金句已植入 ✓」，发布时计「修改后发布」信号 |
| 5 | 发布记账 | 「复制文案」→（口头说明去微信手动粘贴发布，系统不做自动发布）→ 回来点「标已发」：按钮锁为「已发 ✓」不可撤销，干货池水位 -1、今日已发 +1、已发历史新增一条（时间 / 摘要 / 来源池）；再次点击「标已发」位置验证幂等锁定，不重复扣减 |
| 6 | 生活池配图 | 切「生活池」生成，文案卡下方出现配图推荐（#777 脱卷 / #137 高尔夫 / #205 海边），均为生活素材库授权入库图片 |
| 7 | 学习信号 | 「习惯自适应」三卡（换一换 · 次 / 修改后发布 · 次 / 标已发 · 条）随操作实时累计，解释文案「系统每周据此调整取材偏好与文案长度」 |
| 8 | 今日新增素材 | 「今日新增素材」区展示昨晚扫描进账：案例库新增岑晴川案例拆成弹药 ×2 → 案例池 +2；驾驶舱五星好评抽金句 ×2 → 点评池 +2、金句库 +2；交付记录 3 条扫描中 |
