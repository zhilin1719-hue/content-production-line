## 1. 剧本验证内容

从开盯一个对标账号开始，到拿出一篇「合规过审版」口播稿并交接剪辑为止的公域台全链：开盯 → 选题池 → 出稿四步（理念三选一 → 框架二选一 → 生成初稿）→ 合规三层（规则库 → 大模型复核 → 人工终审）→ 复制 / 导出。

## 2. 执行步骤（客户独立完成）

| # | 步骤 | 操作要点 |
|---|---|---|
| 1 | 添加并开盯对标账号 | 「+ 添加对标账号」填账号名 / 平台 / 赛道 / 粉丝量 / 作品数，点「开盯」 |
| 2 | 查看选题池与筛除留痕 | 展开汇总条「挂不上钩自动筛除（留痕）」，确认筛除原因可查 |
| 3 | 挑选题出稿 | 在「选题」状态行点「出稿」 |
| 4 | 理念三选一 | 点一张理念卡，必要时点「重新生成」，点「下一步」 |
| 5 | 框架二选一 | 点一张框架卡，点「生成初稿」 |
| 6 | 核对初稿 | 读初稿，核对像你度数值与来源信息 |
| 7 | 进入合规三层 | 点「进入合规审查 →」 |
| 8 | 第一层处理 | 核对命中的风险词与建议，点「采纳全部建议」，确认重扫 0 处 |
| 9 | 第二层确认 | 确认「连续 8 字重合率 ≤15% · 通过」 |
| 10 | 第三层终审 | 由审核员（另一账号）点「终审通过 · 标记合规过审版」；操盘手自测终审被拒 403 |
| 11 | 取稿 | 成功页「复制文案」与「导出 .txt」各执行一次 |
| 12 | 回查 | 选题池筛选「已出稿」，点「查看」回看全文 |
