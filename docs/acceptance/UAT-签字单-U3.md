## 1. 剧本验证内容

一场公开课从建场次到收官的完整节奏：新建场次（含一次撞期拦截验证）→ 预热 D1~D3 三渠道物料逐日发布 → 正课 D1~D5 逐日生成正文、配图、标已发 → 进度回写至 5/5 → 收官提示与场次状态流转。

## 2. 执行步骤（客户独立完成）

| # | 步骤 | 操作要点 |
|---|---|---|
| 1 | 建场次（撞期验证） | 点「新建场次」，先故意选与在跑场次正课期重叠的预热开始日，确认被拦；再挪开日期正常建成 |
| 2 | 填写校验 | 课程主题超 40 字 / 目标人群超 30 字各试一次，确认被拦 |
| 3 | 预热 D1 | 切 D1 标签：朋友圈文案「换一换」→「复制」；私信话术确认 {称呼} 占位符 →「复制」；宣传海报「下载 PNG」；逐卡「标已发」至 3/3 |
| 4 | 预热 D2、D3 | 逐日切标签、逐渠道发布并「标已发」，各日 3/3 |
| 5 | 海报失败自救 | （如遇下载失败）按口径先「换一换」再「下载 PNG」 |
| 6 | 正课 D1 | 点「上传」挂配图（验证 3/3 上限后按钮禁用）→ 点「生成正文」→「复制正文」→「标已发」，核对进度回写 1/5 |
| 7 | 正课 D2~D5 | 逐日生成、标已发，进度回写 2/5 → 5/5 |
| 8 | 收官确认 | 第 5 天发出后确认提示「正课全部发出，可执行收官动作」 |
| 9 | 泳道核对 | 排期泳道中找到本场，核对新场次条带与阶段色正确 |
