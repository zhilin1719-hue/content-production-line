## 1. 剧本验证内容

四类角色（管理员 / 操盘手 / 审核员 / 查看者）的权限边界与双项目（泽宇 · 高净值变现IP / 岑晴川 · 别墅设计）的数据隔离：越权被拒、跨项目不可见、审计留痕完整。

## 2. 执行步骤（客户独立完成）

| # | 步骤 | 操作要点 |
|---|---|---|
| 1 | 查看者只读 | 登录 viewer（只读账号）：浏览看板与列表正常；调任一写接口（生成 / 标已发 / 淘汰）确认 403 |
| 2 | 操盘手无终审权 | 登录 operator：完成一次生成类写操作正常；调终审接口（final-review）确认 403 |
| 3 | 操盘手跨项目不可见 | operator 访问岑晴川项目（projectId=p-cenqc）的任意资源，确认统一返回「项目不存在或无权访问」（404 口径） |
| 4 | 审核员终审 | 登录 reviewer：对待审稿执行「终审通过 · 标记合规过审版」，确认成功 |
| 5 | 管理员双项目 | 登录 admin：顶栏项目切换按钮在两个授权项目间切换，确认数据域整体切换（选题池、六池、场次互不串用） |
| 6 | 审计核对 | admin 调 GET /api/audit，核对上述步骤 1–5 的写操作与被拒尝试均有留痕（操作人 / 时间 / 角色 / 对象 / 项目） |
| 7 | token 失效 | （口径确认）token 有效期 7 天，过期后接口返回 401，重新登录恢复 |

## 4. 执行记录（本次浏览器实测结论）

2026-09-10 上午，客户方项目负责人在 Chrome 与接口工具中独立完成权限与隔离验证。实测结论：隔离与拦截验证全部通过。viewer 账号只读接口正常、写接口全部 403；operator 账号生成类写操作正常、终审接口 403、访问 p-cenqc 项目资源统一返回「项目不存在或无权访问」（404，无项目信息泄露）；reviewer 账号终审成功；admin 账号双项目切换后页面数据域（选题池、六池、场次）整体切换、互不串用；GET /api/audit 可查到当日全部写操作留痕与 403 / 404 拒绝记录，审计按人、按角色、按项目可过滤。多项目隔离基线（isolation 套件「跨项目一律 404」）在 M1 评审已验证，本次为浏览器与接口层复验。
