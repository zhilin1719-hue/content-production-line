## 1. 剧本验证内容

朋友圈台一周的日常动作循环：五源状态确认 → 六池水位巡检 → 选池生成 → 换一换 / 金句植入 → 复制发布 → 标已发记账 → 水位扣减与信号累计 → 已发历史核对，连续多日重复验证状态流转与幂等。

## 2. 执行步骤（客户独立完成）

| # | 步骤 | 操作要点 |
|---|---|---|
| 1 | 五源状态巡检 | 逐行确认五个数据源「已就绪」，声纹引擎像你度展示 |
| 2 | 六池水位巡检 | 逐卡查看容量与水位百分比，确认见底提醒文案 |
| 3 | 选池 | 点「干货池」（后几日轮换案例 / 生活 / 点评池） |
| 4 | 生成 | 点「生成今日朋友圈」，读文案、核对像你度 |
| 5 | 换一换 | 点「换一换」至少一次，确认变体序号变化与学习信号累计 |
| 6 | 金句植入 | 点「金句植入」，确认金句追加到末尾、按钮变「金句已植入 ✓」 |
| 7 | 复制发布 | 点「复制文案」，口头确认将去微信手动粘贴发布（系统不做自动发布） |
| 8 | 标已发 | 发布动作完成后点「标已发」，核对水位 -1、今日已发 +1、已发历史新增 |
| 9 | 幂等验证 | 再次点击「标已发」位置，确认按钮已锁「已发 ✓」，不重复扣减 |
| 10 | 生活池配图 | 选「生活池」生成一次，确认配图推荐出现（授权图库） |
| 11 | 信号核对 | 「习惯自适应」三卡数字与操作次数一致 |
