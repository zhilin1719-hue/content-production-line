## 2. 演示内容（对照实际原型）

| # | 演示项 | 实际演示路径与结果 |
|---|---|---|
| 1 | 新建场次与撞期 | 点「新建场次」填课程主题（≤40 字）/ 目标人群（≤30 字）/ 主钩子（下拉四选一）/ 预热开始日 → 先演示撞期：所选日期与在跑场次正课期重叠，系统拦下并提示「与『XX』正课期 MM-DD~MM-DD 撞期 —— 把预热开始日挪开再建」→ 挪开后点「建场次」成功，场次状态「筹备中」，toast「物料将于预热日早 8 点前就绪」 |
| 2 | 预热三渠道逐日发布 | 当前场次卡标「今日 D1」，物料区 D1 标签下三张卡：朋友圈文案（读稿 →「换一换」→「复制」）、私信话术（指认 {称呼} 占位符 →「复制」）、宣传海报（「下载 PNG」保存 1080×1440 成品）→ 逐卡点「标已发」，「本日已发」0/3 → 3/3 |
| 3 | 节奏刚性口径 | 切到 D2 标签确认次日物料就绪；讲解并确认口径：当天物料没发不顺延，第二天照常发当天的，预热 3 + 正课 5 共 8 天不断档 |
| 4 | 正课全链 | 正课表 D1 行点「上传」挂配图至 3/3（挂满自动禁用）→ 点「生成正文」出正文弹层（开场钉问题 / 三步走 / 作业指令）→「复制正文」→「标已发」：该行状态变「已发」、场次进度回写「已发 1/5」；演示第 5 天发出后提示「正课全部发出，可执行收官动作」，收官动作人工执行 |
| 5 | 排期泳道 | 泳道图 2026 年 8 月视图：四条泳道（本场 / 疗愈行业 / 从百万到千万已收官 / 小团队做千万筹备中），三种阶段色 + 其他场次灰色；点行标签切换当前场次；图例区提示「同项目同日两条朋友圈物料冲突时，此处给出提示」 |
| 6 | 收官交付物 | 当场清点 D6 培训三件套、D7 运维与应急包、D8 验收与过程档案，与本纪要同套归档 |
