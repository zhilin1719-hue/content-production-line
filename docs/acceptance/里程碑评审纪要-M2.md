## 2. 演示内容（对照实际原型）

| # | 演示项 | 实际演示路径与结果 |
|---|---|---|
| 1 | 开盯与选题池 | 「+ 添加对标账号」填表（账号名 / 平台 / 赛道 / 粉丝量 / 作品数）→「开盯」→ 扫描后选题池入池；展开「挂不上钩自动筛除 2 条（留痕）」，展示「相关度低于阈值 40，未入池(留痕)」样例（如「三天起号秘籍」，相关度 32） |
| 2 | 公域台四步出稿 | 选题池挑一条点「出稿」→ 步骤 1 理念三选一（演示「重新生成」换三张）→ 步骤 2 框架二选一（框架 A 冲突递进 / 框架 B 案例实证）→「生成初稿」→ 步骤 3 初稿展示像你度数值与来源信息 |
| 3 | 合规三层（FR-A7） | 第一层规则库扫描命中 2 处风险（「最好」「第一」，正文高亮 + 逐条改法建议）→ 点「采纳全部建议」自动替换（最好 → 更适合大多数人、第一 → 头部）→ 重扫 0 处通过 → 第二层大模型复核显示「与对标原文连续 8 字重合率 ≤15% · 通过」→ 第三层人工终审点「终审通过 · 标记合规过审版」 |
| 4 | 打回处理 | 演示第三层点「打回修改」，稿子回到初稿页不丢失，改后可重走三层 |
| 5 | 权限闭环 | operator 账号执行出稿全链至第三层，点终审被拒 403；换 reviewer 账号终审通过，体现「终审权永远在人」 |
| 6 | 导出交接 | 成功页「复制文案」按钮变「已复制 ✓」；「导出 .txt」下载《口播稿-低客单不是引流….txt》；选题状态自动变「已出稿」，「查看」可回看全文 |
| 7 | 淘汰与恢复 | 点「淘汰」出现确认弹层（保留 90 天可恢复）；在「已淘汰」筛选项下点「恢复」回到选题池 |
