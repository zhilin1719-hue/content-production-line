## 1. 考核剧本

一场完整公开课，从建场次到收官，途中插入两个规定动作：一次「换一换」、一次合规打回处理。

| 阶段 | 规定动作 | 分值 |
|---|---|---|
| 建场次 | 新建场次（主题 ≤40 字 / 人群 ≤30 字 / 主钩子 / 预热开始日），正确应对一次撞期拦截 | 10 |
| 预热期 | D1 三渠道逐渠道发布并标已发至 3/3；其中任一渠道执行一次「换一换」 | 15 |
| 预热期续 | D2、D3 照常逐日发布（口述节奏刚性口径：当天没发不顺延） | 5 |
| 出稿送审 | 从公域台挑选题 → 出稿四步 → 送审 | 10 |
| 合规打回 | 现场制造一次打回：审核员点「打回修改」，考核对象按风险提示修改后重新过三层至终审通过 | 15 |
| 正课期 | D1 生成正文 → 挂配图（口述上限 3 张）→ 复制正文 → 标已发，核对进度回写 1/5 | 15 |
| 正课收尾 | D2~D5 逐日标已发（可加速操作），确认 5/5 与收官提示 | 5 |
| 记账核对 | 回朋友圈台核对当日标已发记账、水位扣减与已发历史 | 5 |
| **实操小计** | | **80** |
| 理解问答 | 见第 3 节题库抽 4 题，每题 5 分 | 20 |
| **合计** | | **100** |

## 3. 理解问答题库（抽 4 题，每题 5 分）

| # | 题目 | 答案要点 |
|---|---|---|
| 1 | 像你度低于 90% 时系统会做什么？出稿线是多少？ | 自动重写一次再给用户；出稿线 ≥90%（NFR-17） |
| 2 | 合规三层分别是什么？终审权在谁手上？ | 规则库扫极限词 → 大模型复核原创度（连续 8 字重合 ≤15%）→ 人工终审；终审权在审核员 / 管理员，永远在人 |
| 3 | 预热 3 天某天物料没发完，第二天怎么办？ | 不顺延，D2 照常发 D2 的，保持节奏刚性，8 天不断档 |
| 4 | 「标已发」点错了能撤销吗？谁来改？ | 不能撤销（幂等锁定）；误标由管理员后台修正并留审计 |
| 5 | 六池配比是多少？哪类池见底时提示文案不同？ | 干货30/案例20/生活20/点评15/成交10/拒审5；拒审池提示「本周拒掉的已成文可直接生成」 |
| 6 | 发布是系统自动发吗？ | 不是，永远人工复制粘贴，系统不对接个人号自动化工具 |
| 7 | 撞期拦截的规则是什么？ | 新场次正课期（开课日起 5 天）与在跑场次重叠即拦，只能挪预热开始日 |
| 8 | 淘汰的选题去哪了？ | 保留 90 天可恢复，之后自动清除 |
