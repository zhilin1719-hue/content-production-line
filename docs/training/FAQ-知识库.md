## 一、出稿与合规

**Q1. 像你度不到 90 怎么办？**
不用你动手。系统检测到低于 90% 会自动重写一次再给你（页面有提示）。如果重写后你仍不满意，点「局部重写」换掉不满意的段落，或回上一步换框架重新生成。连续三篇都低，属于口吻样本不够，找管理员安排补充声纹样本。

**Q2. 为什么有时点「生成初稿」比平时慢一点？**
生成服务有正常延迟（200–600 毫秒量级），主供应商异常时会自动切备供应商，切换那一次会稍慢。超过 2 分钟没结果才是故障，报 P1。

**Q3. 我的稿子为什么被打回？**
三种可能：第一层命中极限词或承诺性表述且未采纳建议；第二层原创度超标（与对标原文连续 8 字重合率超过 15%）；第三层审核员人工判断有风险。打回时页面上有具体原因，按提示改完重新送审即可，稿子不会丢。

**Q4. 「最好」「第一」这类极限词到底怎么改？**
系统给的是建议替换：最好 → 更适合大多数人、第一 → 头部、史上最 → 删掉、百分百 → 大概率或给具体数字。点「采纳全部建议」一键替换，替换后自动重扫确认为 0 处。你也可以按建议思路自己改，改完以重扫结果为准。

**Q5. 承诺性表述有哪些，替代写法是什么？**
规则库覆盖：稳赚（改成「把确定性做高」）、保证收益（改成「可验证的案例路径」）、躺赚（改成「系统替你跑」）、guaranteed（删掉）。原则：不承诺收益，只讲方法和已核验的案例数字。

**Q6. 原创度 15% 是怎么算出来的？**
把你生成的稿子与对标原文都清洗掉标点空白后，统计「连续 8 个字完全相同的片段」占你全文的比例。≤15% 通过。这意味着你最多化用对方的选题和结构，不能整句搬运。

**Q7. 采纳全部建议之后，还需要人工终审吗？**
需要。合规是三层，第一层机器替换、第二层模型复核都不能替代第三层人工终审。终审权永远在人，操盘手自己不能终审自己的稿子。

**Q8. 打回修改后，之前写的内容会丢吗？**
不会。打回只是回到初稿页，已生成的稿子还在，你接着改。改完重新点「进入合规审查 →」重走三层。

**Q9. 已出稿的选题还能看全文吗？**
能。选题池筛选「已出稿」，点「查看」可回看合规过审版全文，随时「复制文案」或「导出 .txt」再发一次给剪辑。

**Q10. 淘汰的选题去哪了？**
进「已淘汰」列表，保留 90 天，期间点「恢复」可回到选题池继续出稿；90 天后自动清除，不占池子。不要的选题放心淘汰，系统留痕。

**Q11. 选题池为什么经常是空的？**
两种情况：对标账号处于「暂停」状态，新爆款不进池；或者扫描到的内容理念相关度都低于 40（阈值），挂不上钩被自动筛除。点汇总条「挂不上钩自动筛除（留痕）」能看每条被筛的原因。长期空池就换对标账号或调赛道。

**Q12. 加对标账号会被对方看到吗？**
不会。系统只做公开内容扫描与脱敏展示，列表里账号名自动打码（如「透*糖」），不与对方账号发生任何交互。

## 二、朋友圈

**Q13. 池子见底了怎么办？**
见底（水位低于 20%）会出黄色提醒，今晚扫描自动补料，当天先发别的池，不耽误。拒审池的提醒不同：会提示本周拒掉的客户已成文，可直接生成。连续三天同一池见底属于异常，找管理员查五源连通。

**Q14. 六池配比是什么意思？**
干货 30%、案例 20%、生活 20%、点评 15%、成交 10%、拒审 5%，这是长期人设的构成比例。日常你可以任意点池取材，但一周下来大致落在这个比例上，人设才不变形。

**Q15. 「换一换」会不会换出重复的？**
每个池的变体有限循环（如变体 1/3 → 2/3 → 3/3 → 回到 1）。转完一圈会出现你见过的版本，这是正常现象。每次换一换都记入学习信号，你换得多的方向下周会少出，重复感会随使用下降。

**Q16. 「金句植入」是什么？**
从金句库（来自学员好评、你本人的原话沉淀）随机取一句加到文案末尾。植入后这条发布算「修改后发布」信号。不想加就不点，不影响出稿。

**Q17. 配图怎么选，授权规则是什么？**
只有生活池会出配图推荐（如 #777 脱卷、#137 高尔夫、#205 海边），全部来自生活素材库里你本人授权入库的真实图片。规则：只用授权图库，不用来路不明的网图，不盗图。海报由系统程序绘制生成，不含第三方素材，可直接使用。

**Q18. 「标已发」点了能撤销吗？**
不能。按钮锁定为「已发 ✓」，设计上防重复记账。误标（还没发就点了）找管理员在后台修正记账，并说明时间和池子。

**Q19. 误标已发谁来改？**
管理员。操盘手自己没有撤销入口。修正后水位与历史同步回滚，审计里留修正记录。

**Q20. 「今日已发」和「已发历史」有什么区别？**
今日已发是当天计数（每天清零重计）；已发历史是带时间的流水（几点、摘要、来自哪个池），用于复盘和排期参考。

**Q21. 学习信号怎么影响下周？**
系统记录三类信号：换一换次数、修改后发布次数、直接发布条数。你换得多的方向下周少出，你直接发的方向下周多加，文案长度也随之微调。这是自动的，不需要配置。

**Q22. 系统能不能帮我把朋友圈自动发出去？**
不能，也不做。发布永远是人工复制粘贴到微信，系统只负责生成、合规口径与记账。不对接任何个人号自动化工具，这是产品边界，也是账号安全边界。

## 三、公开课

**Q23. 建场次时提示撞期怎么办？**
说明你选的预热开始日推算出的正课期（开课日起 5 天）与在跑场次重叠。把预热开始日往前或往后挪，直到不再撞期。系统不提供强行新建，一场正课期内同项目只跑一场。

**Q24. 当天的物料没发，第二天顺延吗？**
不顺延，节奏是刚性的。D1 没发完，D2 照常发 D2 的。错过的内容当天内可以补发，但第二天必须回到当天节奏。预热 3 天 + 正课 5 天共 8 天不断档，这场课的势能才成立。

**Q25. 海报下载失败怎么办？**
先点「换一换」换一个变体，再点「下载 PNG」。海报是按当前变体实时绘制的 1080×1440 图片，偶发绘制失败换个变体即可。换两个变体都失败再报障。

**Q26. 预热 3 天、正课 5 天的节奏是怎么定的？**
预热 3 天负责拉人进群、发钩子文件；正课 5 天按「诊断 → 三把钥匙 → 一对一应用」展开。开课日 = 预热开始日 + 3 天，正课期 = 开课日起 5 天，全部系统自动推算，你只填预热开始日。

**Q27. 正课的「配图 0/3」是什么？**
每天正文最多挂 3 张配图，点行内「上传」逐张挂，计数实时更新。挂满 3 张按钮自动禁用。配图建议用与当天主题相关的真实场景图。

**Q28. 一场课结束后系统会做什么？**
第 5 天标已发后提示「正课全部发出，可执行收官动作」。收官动作（结课通知、私聊转化、群解散等）由你按既有 SOP 执行，系统不自动做转化动作，场次状态转为「已收官」。

**Q29. 新建场次要填什么，有什么格式要求？**
四项：课程主题（≤40 字，建议「痛点人群 + 结果承诺」）、目标人群（≤30 字）、主钩子（下拉选）、预热开始日。前两项超字数会被拦下，主题必填。

**Q30. 泳道图里颜色分别是什么？**
预热期为橙黄、正课期为主色、收官转化为黄色段、其他场次为灰色。点任意场次名可切换当前操作的场次。同项目同日两条朋友圈物料冲突时泳道会给出提示。

## 四、账号与权限

**Q31. 为什么我看不到某个项目？**
你的账号没被授权那个项目。每个账号有明确的项目清单（如 operator 只见泽宇项目）。访问未授权项目统一返回「项目不存在或无权访问」，不泄露项目是否存在。需要访问找管理员加授权。

**Q32. 查看者账号能干什么？**
只能看：看板、列表、物料、正文。所有写操作（生成、标已发、淘汰、终审）都会被拒（403）。给外部顾问或领导看进度就用这个账号。

**Q33. 谁能做人工终审？**
审核员和管理员。操盘手点终审会被系统拒绝（403），这是合规三层的最后防线，不开放例外。

**Q34. 谁能建新项目？**
只有管理员。建项目后给相应操盘手、审核员、查看者配授权。

## 五、系统与其他

**Q35. 断网了草稿会丢吗？**
页面上的操作状态（选题状态、已发记账、物料变体选择等）存在浏览器本地，网络恢复后仍在；生成中的请求会中断，重新点生成即可，不会产生半篇稿子。服务端数据按项目落盘在服务器的 JSON 文件里，每日有全量备份（详见运维手册），单点断网不影响已保存数据。

**Q36. 演示数据和真实数据怎么区分？**
演示数据在页面右上角一律标注「演示数据」，内容带示例人名与示例数字（如岑晴川 45w 客单价案例）。正式启用后由管理员初始化真实项目数据，真实数据不带该标注。两者不会混存——切换项目即切换数据域。
