## R01 系统总览与登录

- **操作步骤**：打开门户首页 → 依次指认三条内容线入口卡（公域台 / 朋友圈台 / 公开课台）→ 总台看板四项指标（本周可用合规选题 6 条、本周口播初稿 5 篇、朋友圈周产出 12 条、单场物料准备 0.4 人日）→ 六池水位与在跑场次两个小卡 → 「操盘手的一天」时间表（09:00 / 12:00 / 17:00）。
- **旁白要点**：三个台对应一天的三个时段；看板四项指标就是验收口径里的运营指标；页面右上角「演示数据」标注的含义。
- **录制注意**：首页信息多，用鼠标逐卡圈点，节奏放慢。

## R02 公域台 · 开盯与选题池

- **操作步骤**：进公域台 → 点「+ 添加对标账号」填表（账号名 / 平台 / 赛道 / 粉丝量 / 作品数）→ 点「开盯」→ 等扫描完成（toast：首轮扫描 10 分钟内完成）→ 点「暂停」再点「开盯」演示两个状态 → 展开汇总条「挂不上钩自动筛除 2 条（留痕）」看筛除原因 → 用筛选标签「全部 / 选题 / 已出稿 / 已淘汰」各点一遍 → 点一条选题的「淘汰」，在确认弹层讲 90 天保留 → 到「已淘汰」里点「恢复」。
- **旁白要点**：脱敏展示；相关度阈值 40 的筛除逻辑；淘汰保留 90 天。
- **录制注意**：扫描中状态约 2 秒自动复位，提前说「实际等待以页面为准」。

## R03 公域台 · 出稿四步全链

- **操作步骤**：选题池挑一条「选题」状态的行 → 点「出稿」→ 步骤 1 理念三选一：点一张卡（高亮）→ 点「下一步」（顺带点一次「重新生成」演示换三张）→ 步骤 2 框架二选一：点「框架 A · 冲突递进」→ 点「生成初稿」→ 步骤 3 等初稿出来，指认像你度数值与来源信息 → 点「局部重写」看段落变化与像你度联动。
- **旁白要点**：三选一定的是「我们怎么说这件事」，二选一定的是「这篇怎么搭」；像你度低于 90% 系统自动重写一次（NFR-17）；局部重写记入学习信号。
- **录制注意**：生成动画约 2 秒，别剪辑掉，让学员看到真实等待。

## R04 公域台 · 合规三层与打回处理

- **操作步骤**：从步骤 3 点「进入合规审查 →」→ 第一层自动扫描，指认命中的风险词高亮与改法建议（最好 / 第一）→ 点「采纳全部建议」→ 重扫显示 0 处通过 → 第二层自动复核，指认「连续 8 字重合率 ≤ 15% · 通过」→ 第三层先点「打回修改」演示回退到初稿页 → 重新进入合规 → 点「终审通过 · 标记合规过审版」。
- **旁白要点**：三层各管什么（规则库极限词 / 模型复核原创度 / 人工终审）；终审权只在审核员与管理员；打回不丢稿。
- **录制注意**：打回演示务必保留，这是审核员培训的核心镜头。

## R05 公域台 · 过审版导出与交接剪辑

- **操作步骤**：终审通过后的成功页 → 点「复制文案」（按钮变「已复制 ✓」）→ 点「导出 .txt」下载文件，展示文件名规则 → 点「完成」关闭 → 回选题池筛选「已出稿」，点「查看」回看全文，再演示一次复制与导出。
- **旁白要点**：过审版是唯一可交接剪辑的版本；选题状态自动变「已出稿」并归档。
- **录制注意**：下载文件那帧展示浏览器下载栏。

## R06 朋友圈 · 五源状态与六池水位

- **操作步骤**：进朋友圈台 → 逐行念五源状态（声纹引擎像你度 97.2% / 案例库 / 生活素材库 / 驾驶舱 / 审核记录，均「已就绪」）→ 六池区逐卡指认容量与水位百分比 → 点开一个见底的池，展示黄色「水位提醒」文案 → 读今日新增素材区（已学会 / 扫描中两种状态）。
- **旁白要点**：五源每晚自动跑，不用人工投喂；水位低于 20% 见底提醒；今日新增素材展示「昨晚扫描的进账」。
- **录制注意**：六池卡片多，用光标逐个划过，别跳。

## R07 朋友圈 · 生成、换一换、金句、标已发

- **操作步骤**：点「干货池」选中 → 点「生成今日朋友圈」→ 文案卡出来后指认像你度 → 点「换一换」（toast：换过已记入学习信号）→ 点「金句植入」→ 点「复制文案」→ 模拟去微信发布的口播（不切屏，口头说明）→ 回来点「标已发」（toast：记账完成 · 池水位 -1）→ 指认右侧「今日已发」+1、已发历史新增一条 → 再点一次「标已发」位置，展示按钮已锁为「已发 ✓」不可重复。
- **旁白要点**：发布是人工复制粘贴，系统不做自动发布；标已发幂等锁定；生活池才有配图推荐。
- **录制注意**：幂等演示是重点，第二次点击要给特写。

## R08 朋友圈 · 学习信号与已发历史

- **操作步骤**：滚动到「习惯自适应」区 → 指认三个信号卡（换一换 · 次 / 修改后发布 · 次 / 标已发 · 条）与本周合计徽章 → 读解释文案（系统每周据此调整取材偏好与文案长度）→ 回到记账区读已发历史条目结构（时间 / 摘要 / 来源池）。
- **旁白要点**：信号是自动积累的，用得越多下周越准；历史用于复盘。
- **录制注意**：本段偏讲解，配鼠标圈点即可。

## R09 公开课 · 新建场次与撞期拦截

- **操作步骤**：点「新建场次」→ 先演示撞期：填一个与在跑场次正课期重叠的预热开始日 → 点「建场次」→ 展示拦截提示「与『XX』正课期 MM-DD~MM-DD 撞期」→ 把预热开始日挪开 → 正常填写（课程主题 ≤40 字 / 目标人群 ≤30 字 / 主钩子下拉 / 预热开始日）→ 点「建场次」→ 展示新场次卡「筹备中」与 toast「物料将于预热日早 8 点前就绪」。
- **旁白要点**：开课日 = 预热开始日 + 3 天，正课期 5 天，系统自动推算；撞期不给绕。
- **录制注意**：先撞期再成功，顺序不能反。

## R10 公开课 · 预热三渠道物料逐日发布

- **操作步骤**：选中当前场次 → 物料区 D1 标签 → 逐卡操作：朋友圈文案卡读稿 →「换一换」→「复制」；私信话术卡指认 {称呼} 占位符 →「复制」并口头说明替换；宣传海报卡 →「下载 PNG」→ 每张卡点「标已发」→ 指认「本日已发」从 0/3 到 3/3 → 切到 D2 标签，说明 D2 物料已就绪、当天没发完不顺延。
- **旁白要点**：三渠道每天三份，逐日换一换、复制、标已发；节奏刚性：D1 没发 D2 照常发 D2 的。
- **录制注意**：{称呼} 替换用口头强调，不切到微信。

## R11 公开课 · 海报下载与私信话术

- **操作步骤**：海报卡 →「下载 PNG」→ 打开下载文件夹展示 1080×1440 成品 → 故意演示一次失败场景的话术口径：点「换一换」再下载 → 私信话术卡展示三个变体与不同称呼场景的匹配。
- **旁白要点**：海报由系统实时绘制，不含第三方素材；下载失败的标准自救动作是先换一换。
- **录制注意**：展示成品图时长不少于 5 秒。

## R12 公开课 · 正课生成、配图与收官

- **操作步骤**：正课表找一行「未发」→ 点「上传」挂图至 3/3（按钮自动禁用）→ 点「生成正文」→ 弹层读正文结构 → 点「复制正文」→ 点「标已发」→ 指认该行状态变「已发」、场次进度回写「已发 n/5」→ 讲第 5 天发出后提示「正课全部发出，可执行收官动作」，收官动作人工执行。
- **旁白要点**：每天一篇正文 + 钩子文件 + 参考案例 + 最多 3 张配图；进度即时回写。
- **录制注意**：进度数字变化前后各停 2 秒。

## R13 公开课 · 排期泳道看全月

- **操作步骤**：滚动到泳道区 → 指认月份与「今日 N 日」→ 逐行讲四种颜色段（预热 / 正课 / 收官 / 其他场次）→ 点另一场次的行标签，展示全页切换到该场次 → 读图例区提示「同项目同日两条朋友圈物料冲突时，此处给出提示」。
- **旁白要点**：泳道是排期决策入口；点行标签切场次。
- **录制注意**：颜色区分在 1080p 下清晰，无需放大。

## R14 底座 · 项目切换、权限边界与审计

- **操作步骤**：顶栏点「泽宇 · 高净值变现IP ▾」切到「岑晴川 · 别墅设计」，指认 toast「理念库、声纹、六池互不串用」→ 切回 → （接口演示，终端或接口工具）登录 viewer 账号 → 用 GET /api/topics 等只读接口正常返回 → 演示一个写接口被拒 403 → 演示 operator 调终审接口被拒 403 → 管理员 GET /api/audit 查当日写操作流水。
- **旁白要点**：四类角色权限矩阵（管理员 / 操盘手 / 审核员 / 查看者）；未授权项目统一 404 口径；审计按人留痕。
- **录制注意**：接口演示提前准备好命令，避免现场敲错。

## R15 运维 · 健康检查与备份核验速览

- **操作步骤**：终端执行 curl http://127.0.0.1:8399/api/health → 讲解返回字段（ok / version / uptimeSec / dataDir）→ 展示备份目录的 tar 文件命名 → 打开一个备份 tar 抽查其中 projects.json 可正常解析。
- **旁白要点**：健康检查是巡检第一动作；备份核验三步（存在 / 大小 / 可解析）。详细步骤见《运维手册》与《备份恢复手册》。
- **录制注意**：终端字号调大，命令逐条回车。
